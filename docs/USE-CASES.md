# Use Cases

Status: Draft

## UC-01 — Morning resume

As a solo developer, I open the local web hub, select yesterday’s workspace, and continue with restored memory and packed context so the model already knows project decisions.

## UC-02 — Attach repo + graph

As a solo developer, I attach a git repo, run Graphify (or equivalent), and ask “what depends on X?” from the hub.

## UC-03 — Safe AI action

As a solo developer, I ask an agent to delete build artifacts; hub requires confirmation, then logs the decision.

## UC-04 — New machine restore

As a solo developer, I install DEVAIOS on a new Mac, import a backup bundle, and recover workspaces/secrets/plugins.

## UC-05 — Local model day

As a solo developer on M-series hardware, I route coding help to Ollama when cloud APIs are unavailable; CCE fits context into the local window.

## UC-06 — Docker durable demo

As a founder, I `docker compose up` and show the hub; restarting containers does not wipe memory.

## UC-07 — Operator approval (later impl)

As an operator, I approve a high-risk deploy proposal from the HITL inbox with twin evidence attached.

## UC-08 — Token budget control

As a solo developer, I inspect a context pack, see what was summarized vs pinned, and adjust the profile for a smaller local model.
